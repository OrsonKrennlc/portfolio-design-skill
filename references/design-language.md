# 设计语言与组件尺度

按当前页面需要选读。以下是可复用基线，不是要求每页包含全部组件的模板。

## 1. 色彩与字体

| 角色 | 基线 | 使用边界 |
| --- | --- | --- |
| 品牌强调 | `#02542D` | 标题、签名、当前导航、关键控件和地图点 |
| 主体画布 / 主文字 | `#FFFFFF` / `#000000` | 以黑白为主，不把照片强制转成黑白 |
| 亮底次级文字 | `#676767` | 正文说明、日期、标签；普通小字适用 |
| 旧版弱灰 | `#808080` | 可用于色板比较，不作为白底普通小字默认色 |
| 装饰线 | `#EAEAEA` | 1px 分隔；不能独自表达输入边界或焦点 |
| 暗底正文 / 标题 | `#D0D0D0` / `#FFFFFF` | 通过明度分层，避免整段纯白 |
| 可选图纸展板 | `#F6F6F3` | 图纸或抽象预览的局部底板，不改成全站米黄底 |

| 语言或角色 | 首选与回退 | 限制 |
| --- | --- | --- |
| 中文 | `"Noto Serif SC", "Songti SC", "STSong", serif` | 标题与正文均可用宋体 |
| 英文、数字 | `"Anonymous Pro", "Courier New", monospace` | 英文正文、编号、年份、技术参数 |
| 签名 | `"Caveat", cursive` | 仅品牌签名，不用于正文或栏目标题 |
| 藏文 | `"Noto Serif Tibetan", serif` | 仅真实藏文，不用作装饰符号 |

字体文件与加载沿用目标项目；变量声明不等于字体已安装。需要加载时采用有授权的字体来源与回退，检查加载后的真实换行。混排中的数字、外文使用合适的局部字体，不把所有中文交给等宽字体回退。

| 层级 | 桌面参考 | 手机参考 | 说明 |
| --- | --- | --- | --- |
| 章节标题 | 48px | 32px | 行高约 1.2，允许 400–700 字重 |
| 项目标题 | 30–36px | 26px 左右 | 行高约 1.3，不用截断代替换行 |
| 短引言 | 20px | 16px | 行高约 1.6 |
| 正文 | 16–20px | 16px 优先 | 长文行高 1.8–2，宽度约 720px |
| 元数据 | 12–14px | 14px 优先 | 不用小号低对比字容纳长信息 |
| 工具目录展示标题 | `clamp(48px, 7vw, 88px)` | 随容器调整 | 仅适合独立展示层级 |

英文大写短标签可用 `0.08em–0.1em` 字距；长英文正文不沿用这一设置。不要把来源首页移动叠字的 20–30px 当成所有页面主标题的尺度。

## 2. 布局与几何

- 标准内容容器最大 1200px，长文最大约 720px；影像序章和黑白转场可全宽。
- 页边距：大屏上限 150px、中屏约 50px、手机 20px。内容宽度和边距共同约束布局，不能把 1200px 内容再强行塞进较小视口。
- 间距刻度：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 60 / 80 / 100 / 120 / 150px。章节通常 80–150px，内部 20–40px，样式手册可适度收紧。
- 常用断点为 1200px、768px；概览与地图、工具图文条目可在约 900px 转单列。断点以内容能否正常排布为依据，不强迫目标项目改用这些数值。
- 导航高度参考桌面 100px、手机 72px；固定或粘性导航需留出内容与锚点偏移，避免重复顶部留白。
- 网格列使用 `minmax(0, 1fr)`，子项允许 `min-width: 0`。长标题自然换行；必要时对链接、代码或极长单词使用 `overflow-wrap`。
- 移动端重排阅读顺序，不把桌面整体缩小；保留核心参数和操作，不靠隐藏数据变简洁。

| 部位 | 圆角 / 阴影 |
| --- | --- |
| 普通内容分组 | 开放版面与细线；无默认封闭盒子或阴影 |
| 项目图片 | 4px |
| 地图 / 桌面弹窗 | 16px；地图提示 8px，手机地图可 12px |
| 手机项目详情 | 全屏时无圆角，自然滚动 |
| 工具标签 / 肖像 | 局部胶囊 / 圆形；不推广为所有 UI 的形状 |
| 项目悬停或聚焦 | `0 15px 40px rgba(0,0,0,.10)` |
| 弹窗 | `0 20px 50px rgba(0,0,0,.20)` |

## 3. 影像与开场

优先选择能解释空间、材料、光线与地点的真实影像。低饱和是选图倾向，不是统一滤镜。封面裁切须保留主体；详情、图纸与需要阅读的图像用 `contain` 或自然尺寸展示。

### 可选摄影序章

用一张主图和一个核心句建立开场。沿用回声式叠字时，最多采用来源中的五层结构：中心黑色、两侧灰阶递淡；桌面层间偏移约 30px、手机约 15px，依实际字高调整。叠字是视觉副本，辅助技术只读取一句文本；对比不足时调整位置或底部遮罩，不机械照抄黑字叠浅图。

摄影向暗色正文的过渡允许黑色渐变；图片叠字允许有目的的半透明暗部。它们不构成全站装饰渐变的许可。藏文的羽化暗部只是原站特定画面的可读性处理。

Hero 不固定铺满按钮组、标签云或社交图标。向下提示需是可聚焦、可操作的入口，能到达实际下一章；取消不必要的循环箭头动画，不添加圆形底座或高强度光影。

## 4. 组件选择

### 导航与页脚

桌面采用白底、细底线和左右清晰对齐；原站局部使用约 95% 不透明背景与 4px 模糊，不扩大为玻璃面板风格。当前栏目可用深绿、字重和浅绿底表示，并设置 `aria-current="page"`。来源最后修订取消了当前项额外底部深色线。

手机保留品牌与一个菜单入口，栏目、语言控制进入展开面板。菜单按钮暴露展开状态，支持键盘与 Esc。需要双语时使用紧凑 `中 / EN` 控件，不将所有菜单文字同时摆成中英两套。页脚以细线和简短署名收束；姓名与年份来自当前项目。

### 作品列表与详情

- 封面比例 8:5；桌面图文间距约 40–56px，可按条目交替方向。
- 编号 → 项目名 → 简短副标题 → 参数 → 进入详情，使用顶部细线分组。
- 建筑参数可按时间、地点、类型、面积、容积率、绿地率、设计人员排序；只显示实际有值且对当前项目有用的字段。摄影和工具项目不继承这些建筑字段。
- 参数适合 `dl`，标签灰、值黑；标题与元数据均允许完整换行。
- 手机优先标题、图像、参数、正文、操作的自然顺序。DOM 阅读顺序与键盘路径保持合理，不仅依靠 CSS 视觉倒序。
- 整卡链接或按钮不能包含另一层可点击控件。多个动作存在时使用独立明确的入口。
- 详情可为独立页或弹窗，以当前导航模式为准；风格不强制弹窗。

### 分类入口、信息条目与工具目录

- 图片分类入口为 1:1、`cover`、居中文本、整块可点击。黑色遮罩按实际图像调整，保证文字可读；图片缩放上限约 1.05，聚焦与悬停提供等价反馈。
- 履历或奖项使用编号 / 日期与内容的线性分组。同一作品的多项结果可合并，不重复整块标题；只展示当前任务提供的事实。
- 工具条目使用图形预览 → 名称 → 用途 → 标签 → 操作。网格、圆环、点阵与大字母是抽象封面语言，限制在预览区域；主操作、源码入口仅在真实存在时出现。

### 地图、弹窗、表单：仅在需要时使用

- 地图采用浅色底图和深绿标记。14px 视觉圆点可配白描边，但交互命中区域应独立扩大；不能把圆点直径当触控尺寸。提供文本索引，默认避免滚轮缩放干扰页面滚动。
- 地图与概览可桌面双栏、900px 附近转单栏，参考高度桌面 480px / 手机 300px；不用地图填补无内容的首屏。
- 桌面弹窗约视口 90%、最大宽度 1200px、最大高度约 90vh；手机可全屏。使用原生 `dialog` 或目标项目已有的可访问组件，支持焦点圈定、Esc、关闭后返回触发器与背景滚动恢复。
- 画廊主图保留全图，显示序号与总数、前后按钮。若支持方向键，应限定在画廊交互中，避免抢占文本输入。进度圆点不作为唯一导航。
- 表单是对来源风格的扩展：可见标签、明确边界、错误文字和状态播报；不只改变颜色。演示提交明确标为本地演示，不接网络、不伪称成功发送。

## 5. 交互与 Web 验收

反馈时长：150ms 用于颜色和快速状态；300ms 用于遮罩、导航和轻量淡入；500ms 用于图像轻微缩放。缓动参考 `cubic-bezier(.2,.8,.2,1)`。优先动画 opacity、transform 和颜色，不连续动画布局尺寸；减少动态效果时关闭非必要动效与平滑滚动。

以语义、重排和键盘可用性配合视觉检查：

- 普通文本与背景对比目标至少 4.5:1，大字至少 3:1；有识别作用的控件边界、状态与焦点检查相邻颜色对比。照片背景需单独检查，不以色板通过代替实际图像测试。
- 主要操作区采用至少 44×44px 的设计目标；不要把它描述为 WCAG 2.2 AA 对所有目标的硬性尺寸，标准的最小目标尺寸条款另有 24×24px 与例外条件。
- 提供地标、清晰标题层级、跳过导航入口；固定顶栏不遮挡焦点或锚点。
- 320 CSS px 下仍能读与操作；新增双语布局需检查两种语言以及相关断点前后。不要为了通过检查给整个页面裁切溢出。
- 图片保留尺寸或比例，首屏主图避免延迟加载，非首屏图可 lazy；内容图片有准确 alt，装饰副本不重复朗读。
- 双语反馈在切换后仍反映当前状态；不要把携带语言属性的根元素误当按钮添加 `aria-pressed`。沿用现有语言机制，避免两套状态不同步。

如要正式判断标准符合性，查阅当时有效的 [WCAG 快速参考](https://www.w3.org/WAI/WCAG22/quickref/)；上述是本风格的实施检查点，不是完整认证清单。
